# GitHub issue triage for the Avalonia 12 migration

Reviewed 2026-09-10 against `avalonia-12.1.2` (Avalonia 12.1.2, .NET 10). Reviewed all 19 open Apollo issues, relevant discussions, and linked Avalonia issues/PRs. These are retest candidates, not claims that the reported bugs have been reproduced and fixed on their original platforms.

## Lifecycle fix on the follow-up branch

[#214: macOS graceful Quit](https://github.com/mat1jaczyyy/apollo-studio/issues/214) now has an Apollo implementation on `codex/214-graceful-quit`, based on the migration branch. Its upstream blocker, [Avalonia #2736](https://github.com/AvaloniaUI/Avalonia/issues/2736), provides the native shutdown callback; Apollo now coordinates confirmation/save before closing windows and suppresses replacement windows only during application exit.

Eight regression cases pass both headlessly and with real Windows windows (93 checks per mode), including track-only workspaces, repeated requests, Save/Discard/Cancel, cancellation of the save picker, and failed saves. Ordinary window-close behavior remains separately covered. See [the test instructions](README.md#graceful-application-quit-214).

Native macOS Command+Q/menu/Dock Quit and native file-picker interaction still need a smoke test before marking the GitHub issue resolved. This is an explicit follow-up fix, rather than an automatic benefit of the framework upgrade.

## Other issues

- [#407: garbled effects/freezing under rapid input on macOS](https://github.com/mat1jaczyyy/apollo-studio/issues/407) is a **secondary stress-test candidate**, not an established rendering fix. The discussion includes MIDI/cable/load possibilities and improvement when the editor is closed. Use the attached reproducer with the original hardware, compare editor open/closed, and record both UI and physical LED output.
- [#397: Launchpad hot-plug discovery](https://github.com/mat1jaczyyy/apollo-studio/issues/397) and [#480: instability above ten Launchpads](https://github.com/mat1jaczyyy/apollo-studio/issues/480) have no identified fix from this migration. The vendored native MIDI backend was not upgraded. Keep these in physical-hardware testing.
- [#396: escaped characters lost from shared presets](https://github.com/mat1jaczyyy/apollo-studio/issues/396) concerns Apollo's compressed-text representation passing through messaging apps. Updating the clipboard API does not change that encoding; it remains unresolved by these changes.
- The remaining feature/refactoring requests ([#10](https://github.com/mat1jaczyyy/apollo-studio/issues/10), [#279](https://github.com/mat1jaczyyy/apollo-studio/issues/279), [#314](https://github.com/mat1jaczyyy/apollo-studio/issues/314), [#426](https://github.com/mat1jaczyyy/apollo-studio/issues/426), [#446](https://github.com/mat1jaczyyy/apollo-studio/issues/446), [#475](https://github.com/mat1jaczyyy/apollo-studio/issues/475), [#478](https://github.com/mat1jaczyyy/apollo-studio/issues/478)) are not completed by a framework upgrade.
- Already-closed [#472: missing IControl package](https://github.com/mat1jaczyyy/apollo-studio/issues/472) is addressed at the dependency level: the historical CI-package/cache workaround is unnecessary now that Apollo uses current public NuGet packages and `Control`. The migrated restore and builds passed.

## Evidence and test order

The existing suites passed 70 shared native checks on master and the migration, and 83 migrated headless checks in both themes. They establish the covered editor, serialization and window-lifecycle behavior; they do not validate these macOS-specific reports, native keyboard mapping, file-picker interaction or OS compositor output. See [README.md](README.md) for exact coverage and commands.

Start Windows manual checks with #361 and #325. On a Mac, prioritize #466, #385 and #214, then #370, #444 and #437; include #407 in the hardware session. For each report, record whether master reproduces it on the same setup before classifying the migration as fixing it. If master cannot run or no longer reproduces, record that limitation instead of claiming a verified before/after fix.
